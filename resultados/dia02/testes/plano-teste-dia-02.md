# Plano de teste — Dia 2 — Role Prompting

## Objetivo

Verificar se a persona controla tom, método, prioridades e limites.

## Procedimento manual

1. Abrir conversa nova, sem memória ou instruções adicionais.
2. Executar `../../../prompts/prompt-dia-02.md` sem alterações.
3. Salvar a resposta integral em um novo arquivo de resultado.
4. Conferir os critérios abaixo.

## Critérios de aceite

- [ ] Há três hard skills em ordem e duas soft skills com ação concreta.
- [ ] Cada recomendação tem justificativa.
- [ ] O horizonte de 90 dias é respeitado.
- [ ] Não há mais de três tecnologias simultâneas.
- [ ] Ferramentas pagas têm alternativa gratuita.

## Resultado

Criar a partir de `../../../templates/template-resultado.md`.
