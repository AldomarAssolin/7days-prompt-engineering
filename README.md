# 7DaysOfCode — Prompt Engineering

[![7DaysOfCode](https://img.shields.io/badge/7DaysOfCode-Prompt%20Engineering-1F53E5)](https://7daysofcode.io/)
[![Alura](https://img.shields.io/badge/Alura-Desafio-0C0C0E)](https://www.alura.com.br/)

Projeto de aprendizagem desenvolvido durante o
[#7DaysOfCode](https://7daysofcode.io/) de Prompt Engineering da Alura.

## Objetivo

Construir gradualmente um **Tutor Pessoal de Carreira Tech**: um mega-prompt
capaz de analisar meu momento profissional e gerar um plano de estudos
personalizado, realista e orientado a projetos.

## Organização

- `contexto/perfil-base.md`: informações pessoais reutilizadas nos prompts.
- `desafios/`: aprendizado, prompt e reflexão de cada dia.
- `resultados/`: respostas obtidas ao testar os prompts.

## Rotina

Cada desafio será realizado em aproximadamente 20 a 30 minutos:

1. Ler e resumir o conceito do dia.
2. Criar ou aprimorar o prompt.
3. Testar e avaliar a resposta.
4. Registrar o que será reaproveitado no mega-prompt.
